# Code of conduct

KagiCyber is a tool about doing the right thing on the web, and we want the project to work the same way.

- Be respectful and constructive. Critique code and rules, not people.
- Assume good intent, ask before you assume, and help newcomers.
- No harassment, insults, discrimination or sharing of other people's private information.
- Do not use the project, its issues or its pull requests to publish findings about sites you do not own. Report those privately to the site owner.

Maintainers may edit or remove contributions and block participants who break these rules. Report problems to conduct@kagicyber.com.
